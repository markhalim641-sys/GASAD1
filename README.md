# جسد واحد | رِعاية
واجهة React + TypeScript + Vite عربية RTL لنظام إدارة خدمة كنيسة الشهيدين العظيمين أبّا كير ويوحنا.

## التشغيل
1. ثبّت Node.js 20 أو أحدث.
2. افتح مجلد المشروع في Terminal.
3. نفّذ:
   ```bash
   npm install
   cp .env.example .env
   npm run dev
   ```
4. افتح رابط Vite الظاهر في الطرفية.

## ربط الباك إند
اضبط `VITE_API_BASE_URL` في `.env` إلى عنوان API، مثال `http://localhost:4000/api`.

الواجهة تتوقع نقاط النهاية التالية (يمكن تعديلها في `src/api` و`src/pages/PortalPages.tsx` لتطابق الباك إند الفعلي):
- `POST /auth/login` body `{ username, password }`
- `GET /auth/me` response `{ user: { id, fullName, username, roles, permissions, currentStage? } }`
- `POST /auth/logout`
- `GET /dashboard`
- `GET /supervisors`, `/servants`, `/members`, `/attendance/members`, `/followups`, `/inventory`, `/stock-requests`, `/notifications`, `/settings`, `/confessions`, `/reports`, `/audit-logs`

قوائم البيانات تقبل query params: `search`, `page`, `pageSize`، ويفضل أن تعيد `{ data: [], total, page, pageSize }` أو مصفوفة مباشرة.

## ملاحظات مهمة
- لا توجد حسابات تجريبية أو بيانات أعمال ثابتة. البيانات تأتي من API؛ من دون باك إند ستظهر رسالة تعذر الاتصال/تحميل البيانات.
- الصلاحيات في الواجهة لتحسين تجربة الاستخدام فقط، ويجب فرضها والتحقق منها في الباك إند لكل endpoint وعملية.
- صفحة الاعتراف لا تظهر إلا عند وجود `confessions.view` ضمن الصلاحيات القادمة من الخادم. لا ترسل بيانات الاعتراف أصلًا إلى المستخدم غير المصرح له.
- نماذج الإنشاء والإجراءات الحساسة تتطلب تثبيت عقود endpoints النهائية من الباك إند؛ لا يتم عرض نجاح وهمي أو حفظ بيانات محليًا.
- صورة الواجهة المرفقة من المستخدم مضافة كأصل بصري للخلفية. يمكن استبدالها بصورة نظيفة للكنيسة دون نصوص مدمجة عندما تتوفر.

حسابات تجريبية (على السيرفر فقط): `admin / Admin@123` — `supervisor / Super@123` — `servant / Servant@123`


## تحضيرك (رفع وعرض التحضير الأسبوعي)
- الواجهة: `/app/preparations` — الباك إند: `/api/v1/preparations`.
- الشكل: مراحل ← خدام كل مرحلة ← تحضير كل خادم، مع لوحة توضح **من لم يرفع** هذا الأسبوع.
- الصلاحيات (تُفرض في الباك إند):
  - الخادم: يرفع ويرى تحضيره فقط.
  - أمين الخدمة (`SUPERVISOR`): يرى مرحلته فقط ويرفع تحضيره كأي خادم.
  - الأدمن (`ADMIN`): يرى كل المراحل ومن لم يرفع، ولا يرفع تحضيرًا.
  - الوصول لصورة غير مصرّح بها يرجع `404`.
- **القفل الأسبوعي (بتوقيت القاهرة):** الرفع مفتوح طول الأسبوع، ويُقفل الجمعة 8 صباحًا، ويُفتح من جديد الجمعة 12 بالليل (بداية أسبوع جديد). بعد القفل لا يستطيع الخادم الرفع ولا حذف تحضيره.
- الصور تُضغط بـ `sharp` (حتى 1920px، WebP، حذف EXIF) وتُخزَّن كـ Buffer داخل MongoDB بدون Base64.

## المخزن
- الواجهة: `/app/warehouse` و`/app/warehouse-requests` — الباك إند: `/api/v1/warehouse`.
- **خادم المخزن (`STOREKEEPER`)**: يضيف أقسام وأصناف ويعدّل الكميات، ويستقبل طلبات الخدام وأمناء الخدمة من كل المراحل، ويقبل أو يرفض مع تعليق يظهر للخادم. القبول يخصم الكميات تلقائيًا، والرفض يتطلب تعليقًا.
- الخادم وأمين الخدمة: يتصفحون الأصناف ويرسلون طلبات ويتابعون حالتها وتعليق خادم المخزن، ويقدرون يلغوا الطلب قبل مراجعته.
- الأدمن: عرض فقط.

## حسابات التجربة والاختبارات
- `npm run seed:accounts` ينشئ: `admin` و`supervisor` و`servant` و`storekeeper` (كلمات المرور في `server/seed-accounts.js`). غيّرها أو احذفها قبل الاستخدام الفعلي.
- `MONGODB_URI=mongodb://127.0.0.1:27017/jasad_test npm test` — تشغّل اختبارات التحضير والمخزن على قاعدة اختبار **تُحذف بعد الانتهاء** (لا تشغّلها على قاعدة الإنتاج).


## الرتب والحضور والغياب
- **الرتب** (يحددها الأدمن عند الموافقة على طلب التسجيل في `/app/registrations`):
  - مشرف مرحلة، مشرف مساعد (بنفس صلاحيات المشرف)، خادم مرحلة (أي مرحلة من الـ8)، خادم المخزن، خادم الغياب.
  - خادم الغياب لا يفتح له إلا صفحة الحضور والغياب (كل المراحل) لتسجيل حضور القداس والخدمة.
- **لوحة الرئيسية** (الأدمن والمشرفون): من غاب عن القداس، من غاب عن الخدمة، من لم يرفع التحضير، وقسم مميز باللون الأحمر لمن غاب عن القداس **والخدمة** لمدة أسبوعين متتاليين. تعرض آخر أسبوع اتسجّل فيه حضور تلقائيًا، ويمكن التنقل بين الأسابيع.
- **الحضور والغياب** (`/app/attendance`): مراحل ← خدام ← عدد الغياب (قداس / خدمة / إجمالي). خادم الغياب والأدمن يسجلون الحضور لكل مرحلة (الغائب = غير المحدد عند الحفظ)، والمشرف يرى مرحلته فقط، والخادم يرى نفسه فقط.
- الأسبوع يبدأ السبت 00:00 بتوقيت القاهرة (نفس أسبوع التحضير).

## تشغيل أسرع
- للتجربة العادية: `npm run dev:all`. إن كان الموقع بطيئًا على جهازك فشغّل النسخة المبنية: `npm run prod` (تبني الواجهة وتشغّلها مضغوطة بدل وضع التطوير).
- قاعدة البيانات في وضع الاختبار المحلي تحتاج Replica Set (يستخدمها المخزن في المعاملات). Atlas يدعمها تلقائيًا.
